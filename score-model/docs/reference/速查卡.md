> 程序执行以 Python 注册表为准；这页是生成的阅读视图。

- `bass` → `electric_bass_finger`（bass）
- `cello` → `cello`（strings）

- `epiano` → `electric_piano_2`（piano）
- `flute` → `flute`（pipe）
- `guitar` → `acoustic_guitar_steel`（guitar）
- `organ` → `drawbar_organ`（organ）
- `piano` → `acoustic_grand_piano`（piano）
- `sax` → `tenor_sax`（reed）
- `synth` → `lead_2_sawtooth`（synth）
- `trumpet` → `trumpet`（brass）
- `viola` → `viola`（strings）
- `violin` → `violin`（strings）

## 奏法（PY/JSON：`articulation=`）

- `accent`：时值 ×1.00，力度 ×1.20
- `marcato`：时值 ×0.67，力度 ×1.20
- `staccatissimo`：时值 ×0.33，力度 ×1.00
- `staccato`：时值 ×0.50，力度 ×1.00
- `tenuto`：时值 ×1.00，力度 ×1.00

## 装饰音（PY/JSON：`ornament=`，可配 `upper/lower/grace`）

- `grace_short`：前 25%；`appoggiatura_long`：拍上 50%；
- `mordent`：主 45/上邻 10/主 45；`turn`：上 15/主 15/下 15/主 55；
- `trill`：主/上邻 10Hz 交替；默认上邻 = 主音 +1 半音。

## 曲线

- 音频只实现 `dynamics`；`tempo/pedal/brightness/expression` 只作分析/呈现。

## 约束

- 音高 21–108；乐器号先声明；踏板间隔 ≥0.25 拍；
- 标签 `[n1]` 唯一；力度 0–1000 或 ppp…fff。
