# 奏法/装饰音的数学写法（MS 里没有字段）

> 语义名称只存在于**写入层**；写进 MS 的是数字/事件，后面才能计算。

## 0. “邻音”是什么

- 上邻音（upper）：主音上方的调内音，如 C 大调 C5 → D5；
- 下邻音（lower）：主音下方，如 C5 → B4；
- 默认不写时：上邻音 = 主音 **+1 半音**（C5 → C#5），不一定在调内。

PY/JSON 写法（工程区已支持）：

```python
g.note(1, "C5", beat=0, beats=1, ornament="trill", upper="D5")
g.note(1, "C5", beat=2, beats=1, ornament="grace_short", grace="F#5")
```

JSON：

```json
{"pitch": "C5", "beat": 0, "beats": 1, "ornament": "trill", "upper": "D5"}
```

## 1. 奏法（不产生新音符）

| 名称 | MS 里发生的数字变化 |
|---|---|
| staccato | 时值 ×0.5，力度不变 |
| staccatissimo | 时值 ×0.33 |
| tenuto | 时值 ×1.0 |
| marcato | 时值 ×0.67，力度 ×1.2 |
| accent | 时值 ×1.0，力度 ×1.2 |

写法：`g.note(..., articulation="staccato")`；MS 只存**缩短后的时值/力度**。

## 2. 装饰音（展开成音符事件）

| 名称 | 展开（占比） | 需要 |
|---|---|---|
| grace_short | 主音前 25%（从前面借）；前方不足则拍上占 25% | 可选 grace 音 |
| appoggiatura_long | 拍上 50%，主音缩短为 50% | 可选 grace/upper 音 |
| mordent | 主音 45% → 上邻 10% → 主音 45% | upper |
| turn | 上邻 15% → 主音 15% → 下邻 15% → 主音 55% | upper + lower |
| trill | 主/上邻每 100ms 交替（10Hz），末尾主音 | upper |

PY：

```python
g.note(1, "C5", beat=0, beats=1, ornament="turn", upper="D5", lower="B4")
g.note(1, "E5", beat=2, beats=1, ornament="trill", upper="F#5")
```

## 3. 验证

```python
song = g.finish()
print([(e.pitch.step, e.pitch.alter, e.onset_us, e.release_us) for e in song._doc.events])
```

你会看到展开后的具体音符/时值——没有 “trill” 字段，只有数字。

## 4. MD 标签格式

按约定，MD 不写奏法/装饰音字段；需要这些时用 **PY 或 JSON**。
