# 演奏语义对照（实际实现）

> 说明“某个奏法/装饰音/动作，在这套引擎里**具体怎么实现**、参数是多少、哪里不实现”。

## 1. 奏法（articulation）

| 名称 | 实际实现 | 效果 |
|---|---|---|
| `accent` | gate ×1.00，力度 ×1.20 | 时值缩短到 100%，力度 加大 |
| `marcato` | gate ×0.67，力度 ×1.20 | 时值缩短到 67%，力度 加大 |
| `staccatissimo` | gate ×0.33，力度 ×1.00 | 时值缩短到 33%，力度 不变 |
| `staccato` | gate ×0.50，力度 ×1.00 | 时值缩短到 50%，力度 不变 |
| `tenuto` | gate ×1.00，力度 ×1.00 | 时值缩短到 100%，力度 不变 |

写入方式：Guide `g.note(..., articulation="staccato")` 或 JSON `articulation`；
MD 标签格式**暂不支持**奏法字段。

## 2. 装饰音（ornament）

| 名称 | 展开规则 |
|---|---|
| `grace_short` | 主音前 25%（从前音借时间） |
| `appoggiatura_long` | 拍上占主音 50%（从主音借） |
| `mordent` | 辅助音占 10%，需上邻音 |
| `turn` | 四音各 15%，需上/下邻音 |
| `trill` | 主音/上邻音交替，实测 10 次/秒 |

实现方式：`ms_ornament.expand()` 在写谱时**展开成具体音符**（MS 里存展开后的音）；
邻音音高必须由上游给出（MS 不含调号）。

## 3. 演奏转折（turn / action）

| 名称 | 声音实现 |
|---|---|
| `bow_change` | friction：30ms，gain 0.09，band 0.55 |
| `breath` | air：45ms，gain 0.07，band 0.15 |
| `mallet` | wood：25ms，gain 0.1，band 0.3 |
| `retrigger` | click：12ms，gain 0.08，band 0.85 |
| `restrike` | click：10ms，gain 0.07，band 0.95 |
| `key_noise` | click：20ms，gain 0.04，band 0.6 |
| `key_click` | click：14ms，gain 0.05，band 0.9 |
| `inhale` | air：120ms，gain 0.05，band 0.1 |
| `col_legno` | wood：20ms，gain 0.12，band 0.45 |
| `brush` | friction：60ms，gain 0.06，band 0.25 |
| `rim_shot` | click：18ms，gain 0.12，band 0.75 |
| `liaison` | 无瞬态（只作结构/连奏标记） |
| `break` | 无瞬态（只作结构/连奏标记） |

`turn` 用 Guide `g.turn(id, kind)` 或 JSON `turns`。

## 4. 连续参数（curve）

| 参数 | 音频实现 | 说明 |
|---|---|---|
| `dynamics` | ✅ | make_audio 逐样本插值 |
| `tempo` | ❌ | 分析/呈现用，音频不实现 |
| `pedal` | ❌ | 踏板另有 PedalSegment |
| `brightness` | ❌ | 分析/呈现用 |
| `expression` | ❌ | 分析/呈现用 |

## 5. 和声

**没有“和声动作”这种演奏实现**；和声只作为 S02 分析量
（`counterpoint`、`harmonic`、段落四维），用于判定，不生成声音。

## 6. 快速结论

- 奏法：5 种，已实现时值/力度变化；
- 装饰音：5 种，已实现展开（颤音 10Hz）；
- 转折：retrigger/restrike/breath/break/key_noise 有真实瞬态；liaison 无瞬态；
- 曲线：只有 dynamics 真正进音频；tempo/brightness/expression 不实现；
- 和声：只分析，不演奏。
